# Security

gaffer runs Codex on your machine and can give it full access (`sandbox: full`, `network: true`). If you find a way for gaffer to run code, write files or reach the network beyond what a task allows, please report it privately.

**Report it here:** [Report a vulnerability](https://github.com/mokkshchoudhary/gaffer-for-claude-code/security/advisories/new). Only the maintainer can see it.

Please include the gaffer version, your OS, and the task file or steps that show the problem.

Problems in Codex CLI or Claude Code themselves belong with [OpenAI](https://github.com/openai/codex/security) and [Anthropic](https://www.anthropic.com/responsible-disclosure-policy).
